# ABP parsing has no wildcard form, so a broad casino word-match cannot live in
# a subscribed list. If casino creatives still get through after gambling-only
# has been active a few days, add this by hand under Domains -> Regex filter ->
# Deny. Note that broad matching on "bet" is deliberately avoided -- it collides
# with legitimate domains such as betterhelp.com.

#   (^|\.)(casino|slots|onlinecasino)[a-z0-9-]*\.(com|net)$
