# Minesweeper, Jigsaw, Sudoku, Ultimate Word Games) and the MSN ad broker they
# share with Windows Widgets / MSN News.
#
# Format: hosts (0.0.0.0). Add to Pi-hole as an adlist by its raw URL:
#   https://raw.githubusercontent.com/Bonkey-Apps/Bonkey-Saftey/main/lists/ms-game-ads.txt
# Gambling/casino CREATIVES are handled by the StevenBlack gambling-only list
# in adlists.txt -- this file blocks the delivery pipeline they arrive through.
#
# Do NOT add assets.msn.com here. It is shared with Windows Widgets, the Edge
# new-tab page and MSN News, and some Casual Games builds hang on the loading
# screen instead of skipping the ad. It is pinned in lists/allowlist.txt.
